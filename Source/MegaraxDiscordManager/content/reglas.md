# Reglas de Megarax Network

- Respeta a jugadores y miembros del equipo.
- No se permiten exploits, bots externos, fraude, suplantación ni venta no autorizada.
- Reporta vulnerabilidades de forma privada mediante tickets.
- No publiques datos personales, credenciales ni conversaciones privadas.
- Usa cada canal para su propósito y evita spam.
- Las sanciones pueden apelarse por el canal correspondiente.

El desconocimiento de las reglas no elimina la responsabilidad.

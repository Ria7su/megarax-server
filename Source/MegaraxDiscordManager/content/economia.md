# Economía de Megarax

La economía está diseñada para controlar la inflación y premiar actividad real.

**Monedas:** Rax Coin, Mega Coin, Dungeon Coin y PvP Coin.

El Marketplace permite comercio entre jugadores mediante Rax Coin. Las monedas y recompensas provienen de sistemas definidos; no se promete una ventaja competitiva directa mediante pagos.

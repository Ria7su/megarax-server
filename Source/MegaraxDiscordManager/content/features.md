# Características de Lineage II Megarax

## Progresión

- Crónica Interlude sobre L2jMobius.
- EXP y SP: **x30**.
- Buff Slots: **40**.
- Subclases: clase base + 3, no acumulativas.
- Noblesse disponible a partir del nivel 80.
- Encantamiento máximo: **+20**.

## Contenido personalizado

- Zonas de farmeo PvP rotativas con invasiones Borak.
- Megarax Gladiator: duelos PvP con apuestas.
- Dominio, economía, temporadas y progresión de clanes.
- Raids, dungeon privada, contratos de caza y objetivos diarios.
- Marketplace, Rax Coin, skins y servicios Megarax.
- Buffs de NPC con duración de tres horas.

## Filosofía del servidor

Megarax está diseñado para que el progreso individual, la cooperación y la competencia entre clanes formen una economía viva. Las ventajas se obtienen jugando, organizándose y dominando el mundo.

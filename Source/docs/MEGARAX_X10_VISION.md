# SV Megarax x10 - La Cronica Viva

Estado: vision aprobada para desarrollo incremental.

## Promesa del servidor

SV Megarax sera un servidor x10 de nostalgia accesible donde cada sesion produce
un avance visible, jugar con otros tiene valor real y las acciones importantes
quedan registradas en la historia del mundo.

La nostalgia no se basara en sufrimiento artificial. Se conservaran el mundo,
las profesiones, las ciudades, las quests clasicas importantes y el valor de
reconocer a otros jugadores. Los sistemas modernos de Megarax seguiran
existiendo, pero formaran parte de una sola economia y una sola narrativa.

## Reglas de preservacion

1. No se elimina ningun NPC, mod, dungeon, skin, quest o sistema existente como
   parte de la migracion x10.
2. Todo sistema nuevo usa nombres, configuracion y tablas propias hasta que su
   integracion haya sido validada.
3. Los cambios de balance se hacen por capas y con copia de seguridad previa.
4. Ninguna recompensa se publica sin identificar su fuente, su sumidero y su
   valor esperado por hora.
5. Las temporadas archivan historia; no borran personajes, objetos ni legado.
6. Premium puede ofrecer comodidad y cosmeticos, pero no multiplicadores de
   combate o economia.

## Identidad de rates objetivo

| Sistema | Objetivo |
| --- | ---: |
| EXP base | x10 |
| SP base | x10 |
| Adena de monstruos | x10 |
| Drop normal | x1.5-x2 de probabilidad, x1 cantidad |
| Spoil | x3 de probabilidad, x1 cantidad |
| Quest items | x2-x3 |
| Quests retail | XP/SP/Adena x10 |
| Quests originales | Balance individual |
| Vitality/descanso | Recuperacion para casuales, maximo efectivo por definir |
| Premium | Sin bonus de EXP, SP, Adena, drop o spoil |

El x10 es una tasa base, no una tasa publicitaria ocultando multiplicadores
permanentes. Champions, vitality, eventos y consumibles deben mostrar de forma
clara cuando alteran temporalmente la progresion.

## Los cinco pilares

### 1. Viaje con sentido

Las aldeas raciales, Gludio, Dion, Giran y las zonas historicas vuelven a ser
etapas reconocibles. Los teleports y atajos no deben borrar el mapa. Descubrir
una ruta puede desbloquearla permanentemente para ese personaje.

### 2. Profesiones necesarias

Tanks, healers, supports, spoilers, crafters, mercaderes, exploradores y
cazadores tendran aportes verificables. Ninguna profesion sera obligatoria para
entrar a todo el contenido, pero una party variada tendra mejores opciones.

### 3. Economia legible

Adena vuelve a ser la moneda principal de comercio. Las monedas especiales
representan actividades concretas y no sustituyen todo el mercado. El equipo
de grado alto no se regala por iniciar sesion.

### 4. Mundo comunitario

Los jugadores construyen proyectos, abastecen ciudades, protegen caravanas,
descubren amenazas y participan en campanas. El resultado puede habilitar NPC,
rutas, servicios o encuentros durante un periodo definido.

### 5. Memoria permanente

La Cronica personal, los objetos con procedencia, los primeros logros, las
conquistas y los proyectos comunitarios conservan los nombres de todos los
participantes validos, no solo del ultimo golpe o del primer puesto.

## Familias de contenido

- Historia principal: capitulos unicos con decisiones y consecuencias.
- Historias regionales: reputacion y cambios locales.
- Misiones de vocacion: acciones utiles de cada profesion.
- Contratos: objetivos cortos, variables y limitados por cuenta.
- Expediciones: contenido de party con rutas y soluciones alternativas.
- Cronicas mundiales: proyectos en los que participa todo el servidor.
- Historias de clan: territorios, rivalidades, castillos y linajes.

## Criterio de calidad de una quest original

Una quest nueva debe tener una razon narrativa, utilizar al menos dos tipos de
accion, aprovechar una localizacion reconocible, tener un presupuesto economico
y dejar una decision, consecuencia o registro. Repetir un contador de muertes
con otro nombre no convierte una mision en contenido original.
